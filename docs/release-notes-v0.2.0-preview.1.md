# 极简睡眠 0.2.0 开发预览 1

这是供试用的 Android 调试签名 APK，应用内版本为 `0.2.0-dev`（versionCode 2），不是经过整夜验收的正式版。

## 本版可用

- 离线循环播放原创合成的大雨、海浪，以及白、粉红、棕噪声。大雨与海浪是声音近似，不是实地录音。
- 媒体后台播放、锁屏媒体控制、应用内音量和 15/30/60/90 分钟或整晚选择。
- 在用户授权后记录一般声音事件片段，保存在应用私有目录；可查看、回听和删除。播放区间及受干扰片段会标记。
- 无账号、广告、分析 SDK 和网络权限；录音不会随源码或 APK 上传。

## 验证范围

- `lintDebug testDebugUnitTest assembleDebug` 构建成功；8 个 JVM 测试与 4 个 Python 素材测试通过。
- Android API 36 真机确认白、粉红、棕噪声可听，短时锁屏播放及媒体暂停有效；一次短录音和原音回听有效。
- 大雨和海浪已打入 APK，文件格式、哈希和循环首尾检查通过；发布时尚未取得真机听感确认。

## 重要限制

- 当前只按未校准的声音能量保存片段，**不会自动识别鼾声、人声或梦话**；不提供睡眠评分、深睡或呼吸暂停判断。
- 助眠声可能被麦克风录入。播放区间和干扰标记并不消除回声。
- 15 分钟实际到期淡出、耳机拔出、长时锁屏录音及整夜可靠性仍待真机验证。
- APK 使用开发机的调试签名。后续若改为正式签名，可能无法直接覆盖安装；请先备份自己需要的记录。本版尚无导出功能，卸载会删除应用私有录音。
