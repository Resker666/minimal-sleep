# Android 界面 A 方案

2026-09-27。仅调整 Android Compose 界面；iOS 工程不在本次范围。

## 页面结构

- **今晚**：当前声音、播放/暂停、音量；定时关闭；夜间记录。声音库从“换声音”进入，保留两段雨声、合成大雨、合成海浪、白噪声和本地导入。
- **记录**：按日期浏览，显示有效采集时长和中文状态。进入一晚后，先显示片段数和真实录音时间轴，再列片段。
- **设置**：跟随系统/浅色/深色；开始记录时是否同时播放；实验性高灵敏度；本机存储与识别说明；音频作者和许可。

使用系统字体、自绘线条图标、浅灰/深灰底色、圆角分组卡片和蓝色主操作。没有引入 Apple 字体、SF Symbols、商业图片或新的依赖。新增图标为本项目原创代码，按根目录 Apache-2.0 许可提供。

## 交互与数据

- 外观、同时播放和灵敏度保存在本机偏好中；录音期间禁止修改两项录音设置。
- 播放与记录仍分别启动。开始记录时是否自动播放会显示在记录卡片下方；定时只结束助眠声。
- 声音库和定时使用底部面板。导入使用 Android 系统文件选择器，原有数量/空间限制保留。
- 记录列表使用惰性列表；诊断信息默认折叠。片段菜单包含识别详情、修改标签和删除。删除片段、整夜记录或导入副本需确认。
- 时间轴仍只定位已保存片段；未保存时段明确提示，并提供附近片段入口。片段内进度条继续支持拖动。
- 播放干扰、采集中断和分类未完成提示保留。模型版本、原标签与未校准分数可在识别详情查看。没有生成睡眠评分或虚构波形。
- 本次没有修改 Room schema、采集阈值、分类规则或音频资源。

## 真机检查步骤

1. 查看“今晚”的播放、定时、开始记录是否清晰可达；在设置切换浅/深/系统，关闭重开 App，检查偏好是否保留。
2. 打开声音库，分别选择内置声音；导入一段自己的本地音频并播放。删除操作应只影响 App 内副本，当前使用的声音不可删除。
3. 定时选 15 分钟；单独播放、单独记录、同时运行分别短测。结束记录确认框选“继续记录”应保持运行，选“结束”应保存。
4. 查看旧夜间记录、时间轴空白位置、已保存片段与片段内拖动；查看播放干扰和识别详情。
5. 调整标签并恢复模型标签；删除确认框先取消，验证数据仍在。仅用新测试片段验证确认删除，不删除用户旧录音。
6. 用大字体和小屏设备检查换行、滚动及触控；使用 TalkBack 检查无文字按钮和进度条。测试后恢复系统字体和外观设置。
